# Designer Bio.fm-Style Demo Profile

A beautiful, responsive, dark-mode-ready one-page profile inspired by [bio.fm](https://bio.fm) for designers, built with [Astro](https://astro.build) and [Tailwind CSS](https://tailwindcss.com).

## ✨ Features
- One-page layout
- Bio, image, links, and portfolio section
- Dark/Light mode toggle
- Responsive, mobile-first design
- SEO optimized
- Accessible and fast-loading

## 🚀 Setup & Development

1. **Install dependencies:**
    ```bash
    npm install
    ```
2. **Start the dev server:**
    ```bash
    npm run dev
    ```
3. **Build for production:**
    ```bash
    npm run build
    ```
4. **Preview production build:**
    ```bash
    npm run preview
    ```

---

## 🌐 Deployment Notes
- Ready for deployment on [Netlify](https://www.netlify.com/) or [Vercel](https://vercel.com/)
- Output is in `dist/` after build
- [netlify.toml](netlify.toml) configured for Netlify static deployment

---

## 🖌️ Customization
- Bio data and links editable in `/src/pages/index.astro`
- Assets (profile image) in `/src/assets/`
- Tailwind config at `/tailwind.config.js`
